# Замер скорости интернета

Консольный скрипт на Node.js. Делает 10 последовательных запросов к указанному адресу, дожидаясь полного ответа на каждый, и выводит статистику.

## Требования

- Node.js 18 или новее (используется встроенный `fetch`)
- Внешние зависимости не нужны

## Запуск

```bash
node speedtest.js <url>
```

Пример (тяжёлая картинка):

```bash
node speedtest.js https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

## Что делает скрипт

1. Принимает адрес из аргумента командной строки.
2. Выполняет 10 запросов **строго по очереди**, каждый раз дожидаясь полной загрузки тела ответа.
3. Считает среднее время запроса и общий объём скачанных данных.
4. Печатает скорость скачивания.

## Пример вывода

```
#1: 10240.5 КБ за 812 мс
...
--- Результат ---
Успешных запросов: 10 из 10
Среднее время запроса: 790 мс
Всего скачано: 100.00 МБ
Скорость скачивания: 106.20 Мбит/с
```

## Единицы измерения

- Время — миллисекунды (мс).
- Объём данных — мегабайты (МБ, 1 МБ = 1024 × 1024 байт).
- Скорость — **мегабиты в секунду (Мбит/с)**, как принято у интернет-провайдеров.

Формула: `скорость = (скачано байт × 8) / суммарное время запросов (с) / 1 000 000`.

## Заметки

- Если часть запросов завершилась ошибкой, она выводится в консоль и не учитывается в статистике.
- Если все запросы неудачны, скрипт завершается с кодом 1.
- Результат зависит от сервера, на который идут запросы, поэтому для честного замера лучше брать крупный файл на быстром CDN.
